## What Tack Harness does

Tack Harness is a **programming workflow framework** purpose-built for software R&D teams using AI coding agents. It organizes the development process along two axes: the software engineering lifecycle (time) and a project directory structure aligned to development habits (space).

## Key design principles

| Principle | What it means |
|-----------|---------------|
| **Fixable process** | Anything a script can do never relies on the LLM — fixed-flow scripts guarantee stability and keep token costs down |
| **Extensible capabilities** | Adding one Markdown file registers one new capability; no changes to the skill itself |
| **Traceable state** | `status.yaml` is the single stateful file — the AI always knows current progress and next action |
| **Isolated changes** | Git worktrees isolate code changes per requirement; the main repo stays a read-only baseline |
| **Distilled experience** | Every completed task automatically crystallizes practical experience into commands, workflows, rules, or wiki entries |

## Getting started

<Steps>
  <Step title="Install the skill">
    Install Tack into your AI agent (TRAE, Cursor, Windsurf, Claude Code, or others):
    ```bash
    curl -fsSL https://raw.githubusercontent.com/frcoder-lh/tack-harness/master/install.sh | sh -s
    ```
    Or ask your agent directly: `Install this skill: https://github.com/frcoder-lh/tack-harness`
  </Step>
  <Step title="Initialize a project space">
    In an empty directory, run `/tack` to trigger initialization. Tack sets up the workspace skeleton, initializes a Git repository, and guides you through connecting your code repositories.
    ```text
    /tack
    ```
  </Step>
  <Step title="Create your first workspace">
    Create a workspace for a requirement. Tack generates branch name candidates, infers involved services, and creates git worktrees.
    ```text
    /tack work user-login
    ```
  </Step>
  <Step title="Run the development chain">
    Walk through the full R&D chain for the requirement:
    ```text
    /tack spec && /tack plan && /tack code
    /tack commit && /tack push && /tack merge
    /tack close
    ```
  </Step>
</Steps>

<Note>
  All commands support Chinese and English triggers plus short forms. Inside a tack-activated conversation the `/tack` prefix can be omitted — just type the command or use natural language.
</Note>
